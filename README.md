# Игра с гоблинами

Домашнее задание по теме «Обработка событий».

[![Сборка](https://github.com/Zloboglaz/ahj-events/actions/workflows/pages.yml/badge.svg)](https://github.com/Zloboglaz/ahj-events/actions/workflows/pages.yml)

[Ссылка на игру](https://Zloboglaz.github.io/ahj-events/)

## Описание

Игра с гоблинами на поле 4×4.

Гоблин появляется в случайной клетке каждую секунду. Нужно успеть нажать на него мышкой.

За попадание даётся одно очко. Если не успеть нажать, засчитывается промах. После пяти промахов игра заканчивается.

Чтобы начать заново, нужно обновить страницу.

## Запуск

Установить зависимости:

```bash
yarn install
```

Запустить проект:

```bash
yarn start
```

## Проверка

Запуск тестов:

```bash
yarn test
```

Проверка ESLint:

```bash
yarn lint
```

Сборка проекта:

```bash
yarn build
```
